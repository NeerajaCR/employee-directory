# Employee Directory Application

A mobile application built with "React Native" and "Expo SDK 56" to search, filter, and view employee details in an organization. 

---

# Features

- Employee List: A scrollable flat list showing employee profiles.
- Search & Filter: Real-time, case-insensitive search by employee name.
- Simulated Loading State: Simulates network request delay with a clean loading spinner before loading the employee list.
- Employee Details Screen: Comprehensive detail page for each employee, showing profile pictures, contact information, role details, and address.
- Native Routing: Smooth transition animations and header navigation built with React Navigation 7.
